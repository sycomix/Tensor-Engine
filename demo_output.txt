3. GRU Gate Functions

   Reset gate (r_t):  Controls how much past info to forget
   Update gate (z_t): Controls how much new info to add
   New gate (n_t):    Candidate hidden state

   Output: h_t = (1 - z_t) * n_t + z_t * h_{t-1}
   ΓåÆ Interpolates between new and old hidden state
